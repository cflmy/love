# 六、两个人的“人物卡”

这里我特别建议把你们之前生成的两个头像真正做成网站里的核心视觉资产。

### 女主人公

使用你提供的原始照片作为原型，但采用：

**QDQC 蓝白水彩 / 东方插画风**

保留她比较有辨识度的：

* 发型
* 五官比例
* 眼睛
* 脸型
* 蝴蝶元素

而不是完全 AI 重新创造一个“网红脸”。

### 男主人公

同样处理。

重点保留：

* 黑色蓬松头发
* 圆框眼镜
* 脸型
* 眼睛
* 微笑
* 原照片的整体气质

然后把服装和环境转换成：

**蓝白东方 / 月夜 / 山水 / QDQC**

这样两个人才真正像“同一个故事里的两个人”。

# 十一、照片不要直接平铺

这一点非常重要。

不要：

```text
[照片][照片][照片]
[照片][照片][照片]
```

这样非常像相册。

而是做成：

### 「漂浮的记忆」

照片像漂浮在水面。

有的：

* 竖着
* 横着
* 倾斜 3°
* 倾斜 -4°
* 藏在花枝后
* 部分被云遮住

点击之后才完整展开。

这会和你们 NFC 卡上的“错落排版”统一起来。
